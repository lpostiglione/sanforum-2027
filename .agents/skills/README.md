# Discourse authoring skills

Repository-local copies from
[discourse/discourse-theme-skills](https://github.com/discourse/discourse-theme-skills),
pinned to commit `45508d28431748d464871a83e3e6026af03992e2`.

- [discourse-theme-authoring](discourse-theme-authoring/SKILL.md): theme structure,
  styles, native variables, localization, settings, icons and extension points.
- [discourse-block-authoring](discourse-block-authoring/SKILL.md): guidance when
  adding or changing Discourse block components.

These skills are development guidance, not theme assets. They are installed in
`.agents/skills` for repository-scoped discovery; nothing was installed globally.
The upstream skill files and their reference appendices are unmodified.
Their [MIT license](DISCOURSE-LICENSE) is retained alongside them.
