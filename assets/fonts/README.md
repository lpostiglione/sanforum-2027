# Source Sans 3

Source Sans 3 is Adobe's humanist typeface designed for user interfaces. These
unmodified variable WOFF2 fonts come from the official Google Fonts distribution
of [Adobe Source Sans](https://github.com/adobe-fonts/source-sans).

The Latin and Latin Extended subsets cover German, including capital ẞ. Both
upright and italic files support weights 200–900. They are served by Discourse
from the theme's own assets; no Google Fonts request is made by the browser.
